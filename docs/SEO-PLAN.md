# План SEO — Checkout Lab

Цель: чтобы по запросам вроде «счётчик дартса», «калькулятор дартса», «таблица закрытий дартс», «darts scorer» сайт находили в Яндексе и Google.

## Сделано (7 октября 2026)
- Картинка превью ссылок `og-image.jpg` (1200×630) на всех 12 страницах, `twitter:card` = `summary_large_image`.
- `sitemap.xml`: все 12 страниц с `hreflang` (RU / EN / x-default) и свежим `lastmod`.
- Заголовок и описание страниц больше не подменяются скриптом после загрузки (#18).
- Ранее: canonical, hreflang, Open Graph, JSON-LD WebSite/WebApplication, robots.txt, подтверждение Яндекса.

## Сделано (страницы под поиск)
- 338 страниц закрытий: `/checkout/2.html` … `/checkout/170.html` и английские `/en/checkout/…` — маршрут, пояснение по каждому дротику, запасные варианты, совет для bogey numbers, разметка `FAQPage` и `BreadcrumbList`. Генерируются командой `npm run build:seo` из логики `app.js`.
- Словарь терминов `darts-terms.html` (RU/EN) с разметкой `DefinedTermSet` и `FAQPage`.
- Разметка `FAQPage` на таблице закрытий, номера в таблице ведут на страницы остатков.
- `sitemap.xml` генерируется тем же скриптом (352 адреса).

## Сделать владельцу сайта (нужен доступ к аккаунтам)
1. **Яндекс Вебмастер** — https://webmaster.yandex.ru: сайт уже подтверждён файлом `yandex_d5470291c7978f06.html`.
   - «Индексирование → Файлы Sitemap» → добавить `https://checkoutlab.ru/sitemap.xml`.
   - «Индексирование → Переобход страниц» → отправить главную и таблицу закрытий.
   - «Информация о сайте → Регион» → Россия.
2. **Google Search Console** — https://search.google.com/search-console: добавить ресурс `checkoutlab.ru`.
   - Подтвердить: Google даст HTML-файл или meta-тег — прислать его, я добавлю в репозиторий.
   - «Файлы Sitemap» → `sitemap.xml`; «Проверка URL» → «Запросить индексирование» для главной.
3. **Яндекс Метрика** (по желанию) — дать номер счётчика, добавлю код, чтобы видеть посетителей и запросы.
