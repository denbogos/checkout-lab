CHECKOUT LAB 1.0 FINAL

Что нового:
- просмотр выхода любого игрока без смены очереди хода;
- Screen Wake Lock: экран не гаснет во время матча (если браузер поддерживает);
- красивый Double Out: выбор последнего удвоения/BULL и числа использованных дротиков;
- проверка невозможных сумм за 3 дротика (например 179/178);
- защита от двойного Enter;
- редактирование/удаление последнего подхода нажатием на последнюю строку истории;
- Ctrl+Z / Ctrl+Shift+Z на ПК;
- опциональные звук и вибрация;
- режим «У мишени» / fullscreen;
- сохранение матча + Undo/Redo между перезагрузками;
- офлайн PWA;
- события 180 / BUST / LEG / MATCH;
- точный dart count при закрытии для корректного AVG.

Netlify:
1. Распакуйте ZIP.
2. Откройте существующий проект checkout-lab-darts в Netlify → Deploys.
3. Перетащите распакованную папку в ручной deploy.
4. После публикации на ПК сделайте Ctrl+F5. На телефоне полностью перезапустите страницу/PWA.

Сборка проверена программно:
- все checkout-маршруты для остатков 2–170 и 1/2/3 дротиков;
- Double Out заканчивается удвоением/BULL;
- bogey numbers не получают ложного закрытия;
- невозможные суммы 178/179 блокируются;
- 4 игрока, переключение хода, Undo/Redo;
- редактирование/удаление последнего подхода;
- защита от двойного подтверждения;
- сохранение game + undo stack.
