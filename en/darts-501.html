How 501 works

Every player starts on 501. The total of each three-dart visit is subtracted. In Double Out, the leg must finish on a double or BULL.

How to score 501 darts

Each player begins on 501. A 100 visit leaves 401. If a visit takes the score below zero, leaves 1, or reaches zero without a finishing double, it is a BUST and the score returns to the value before the visit.

501− 100 →401− 140 →261

When checkout routes start

The highest three-dart checkout is 170: T20 → T20 → BULL. Checkout Lab shows a finish when one exists and a setup route when it does not.
