# 🎯 Checkout Lab

**Checkout Lab** — бесплатный калькулятор и счётчик для дартса 301/501 с подсказками закрытий, Double Out, статистикой и полноценным офлайн-режимом.

🌐 **Сайт:** https://checkoutlab.ru/  
📋 **Таблица закрытий 2–170:** https://checkoutlab.ru/checkout-table.html

## Возможности

- 🎯 игры **301 / 501** и произвольный стартовый счёт;
- 👥 до **8 игроков**;
- 🧮 быстрый подсчёт очков и остатка;
- 🏁 подсказки оптимальных **Double Out** закрытий;
- 🔢 в маршрутах с двумя утроениями первым показывается **большее утроение** (например, T20 → T19 → D20);
- 📋 отдельная таблица закрытий **2–170**;
- 📊 статистика матча и средний набор;
- ↩️ Undo / Redo с сохранением между перезагрузками;
- ✏️ редактирование и удаление последнего подхода;
- 🚫 проверка невозможных сумм за три дротика;
- ⚡ защита от двойного подтверждения результата;
- 🔊 звук и вибрация;
- 🖥️ полноэкранный режим **«У мишени»**;
- 💡 Screen Wake Lock — экран не гаснет во время игры, если браузер поддерживает API;
- 🎉 события **180 / BUST / LEG / MATCH**;
- 📱 адаптивный интерфейс для телефона и компьютера;
- 📴 **PWA и офлайн-режим** после первого открытия.

## Как пользоваться

На компьютере результат подхода можно вводить с клавиатуры: набрать сумму и нажать **Enter**.  
**Ctrl+Z** отменяет последнее действие, **Ctrl+Shift+Z** возвращает его.

На телефоне используется крупная сенсорная клавиатура. Через меню доступны матч, закрытия, полная таблица 2–170, статистика и режим «У мишени».

## Закрытия

Checkout Lab показывает основной маршрут и запасные варианты для Double Out. Используются стандартные обозначения:

- **S20** — одинарный сектор 20;
- **D20** — двойной сектор 20;
- **T20** — тройной сектор 20;
- **BULL** — 50 очков.

Для просмотра всей таблицы без запуска матча откройте:  
https://checkoutlab.ru/checkout-table.html

## PWA и офлайн

Приложение можно установить на главный экран телефона или как веб-приложение на компьютере. Основные файлы и таблица закрытий кэшируются Service Worker, поэтому после первого открытия Checkout Lab продолжает работать без интернета.
